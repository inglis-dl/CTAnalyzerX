Common Issues & Solutions
===============================================================================

1. LNK2038: mismatch detected for 'RuntimeLibrary'
   -> All projects MUST use same runtime: /MTd (debug) or /MT (release)
   -> Set CMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded$<$<CONFIG:Debug>:Debug>

2. Qt static linking requires Q_IMPORT_PLUGIN macros
   -> Qt5 static build bundles plugins into executable
   -> Add in main.cpp:
     #include <QtPlugin>
     Q_IMPORT_PLUGIN(QWindowsIntegrationPlugin)
     Q_IMPORT_PLUGIN(QICOPlugin)

3. VTK OpenGL errors on static build
   -> Ensure VTK uses same Qt5 as application
   -> Verify Desktop OpenGL (not ANGLE/ES)

4. ITK GDCM conflicts with system GDCM
   -> Always use ITK's internal GDCM (USE_ITK_GDCM=ON)
   -> Do not mix external GDCM

5. CMake cannot find Qt5
   -> Set CMAKE_PREFIX_PATH=D:\build\qt5-static
   -> Or set Qt5_DIR=D:\build\qt5-static\lib\cmake\Qt5

6. Missing double-conversion.lib
   -> VTK builds internal double-conversion
   -> Ensure VTK_MODULE_USE_EXTERNAL_VTK_doubleconversion=OFF

7. Git clone fails with SSL certificate errors
   -> Update Git: git update-git-for-windows
   -> Or disable SSL verification (not recommended): git config --global http.sslVerify false

8. Qt init-repository fails
   -> Ensure Perl is installed (Strawberry Perl or ActivePerl)
   -> Add Perl to PATH: set PATH=C:\Strawberry\perl\bin;%PATH%
